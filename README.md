# EducationalTop

EducationalTop is a MATLAB educational repository that aims to provide simplified versions of different topology and shape optimization developments. This repository contains educational implementations of methods developed in separate research repositories.

For now, the following developments are included:

### 1) [ShapeTop](./ShapeTop/)

ShapeTop implements a shape optimization approach based on constrained density-based topology optimization for 2D structures.

### 2) [MultiLoadTop](./MultiLoadTop/)

MultiLoadTop addresses structural topology optimization problems involving multiple load cases. Different optimization approaches are included, such as Pareto-based methods, weighted sums, P-norm and KS approximations, and dual formulations.
